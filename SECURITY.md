# Security Policy

## Supported Versions
Only the latest released version receives security patches and updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.8.x   | :white_check_mark: |
| < 1.8.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability in TesseraDesk, please report it privately via GitHub Security Advisories or by creating an issue labeled with security.

We will review and patch verified vulnerabilities promptly.
