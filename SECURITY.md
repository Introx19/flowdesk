# Security Policy

## 🛡️ Supported Versions

We actively support the latest release branch of **TesseraDesk** with security fixes and maintenance updates.

| Version | Supported          | Status |
| :------ | :----------------: | :----- |
| 1.8.x   | :white_check_mark: | Active (Recommended) |
| 1.7.x   | :x:                | Deprecated |
| < 1.7.0 | :x:                | End of Life |

---

## 🚨 Reporting a Vulnerability

The TesseraDesk team takes the security of our application and users seriously. If you discover a security vulnerability (e.g. IPC sandbox escape, remote code execution, token leakage, or privilege escalation), please report it responsibly:

### How to Report:
1. **GitHub Security Advisory (Preferred):** Go to the repository's **[Security tab](https://github.com/Introx19/TesseraDesk/security)** and click **"Report a vulnerability"**.
2. **Private Issue:** If private reporting is unavailable, open an issue with the prefix `[Security]` without exposing critical exploit details publicly.

### What to Include:
* Description of the vulnerability and its potential impact.
* Steps or minimal proof-of-concept (PoC) to reproduce the issue.
* Your operating system (Windows 10/11) and TesseraDesk version.

### What to Expect:
* **Response time:** We will acknowledge your report within **48 hours**.
* **Fix & Release:** Confirmed vulnerabilities will be patched and deployed via auto-update in the next minor version release.
